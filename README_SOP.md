# საწყობის ნაშთების აღრიცხვა — გამოყენების ინსტრუქცია (SOP)

## რას აკეთებს სისტემა

ყოველდღიური 1C რეპორტიდან ("ნომენკლატურის მოძრაობა საწყობზე") ტრანზაქციები იწერება სააღრიცხვო ფაილში ნიშნით (+/−), რის შედეგადაც ყოველ SKU-ზე ინახება მიმდინარე ნაშთი და სრული ისტორია (ჟურნალი). დამთხვევა ხდება 1C-ის შიდა კოდით (კოდი), არა დასახელებით.

## ფაილები

| ფაილი | დანიშნულება |
|---|---|
| `app.py` + `engine.py` | Streamlit აპლიკაცია |
| `requirements.txt` | საჭირო Python ბიბლიოთეკები |
| `სააღრიცხვო_ფაილი.xlsx` | სააღრიცხვო ფაილი: ნაშთები (386 SKU) + ცარიელი ჟურნალი |

სააღრიცხვო ფაილის ფურცლები: **ნაშთები** (საწყისი და მიმდინარე ნაშთი), **ჟურნალი** (ყველა ტრანზაქცია დეტალურად), **დღიური ნაშთები** (ყოველ ატვირთულ დღეზე ორი სვეტი — დღის ცვლილება და ნაშთი დღის ბოლოს; ივსება ავტომატურად პირველი დაწერიდან), **ინსტრუქცია**.

## ერთჯერადი მოწყობა

1. დააინსტალირეთ Python 3.10+ (python.org).
2. საქაღალდეში, სადაც ფაილები დევს: `pip install -r requirements.txt`
3. გახსენით `სააღრიცხვო_ფაილი.xlsx` და შეავსეთ ყვითელი სვეტი **"საწყისი ნაშთი"** ინვენტარიზაციის ან 1C ნაშთების რეპორტის მიხედვით. ეს კეთდება ერთხელ.

## ყოველდღიური პროცესი

| # | ვინ | მოქმედება |

| 2 | საწყობის სპეციალისტი | ხსნის ფაილს Excel-ში და **თითოეული ოპერაციის სვეტის სათაურის ზემოთ** (მე-5 სტრიქონი) წერს ერთ ასოს: **მ** = მიღება (+), **დ** = დაბრუნება (+), **გ** = გაცემა (−), **ჩ** = ჩამოწერა (−). ინახავს ფაილს. |

| 4 | საწყობის სპეციალისტი | ტვირთავს ორ ფაილს: დღის ფაილი + მიმდინარე სააღრიცხვო ფაილი |
| 5 | საწყობის სპეციალისტი | ამოწმებს გადახედვას: ოპერაციების ჯამები, გაფრთხილებები |
| 6 | საწყობის სპეციალისტი | აჭერს "დაწერე ჟურნალში", ჩამოტვირთავს განახლებულ ფაილს და **ანაცვლებს ძველ ვერსიას** |

## ჩაშენებული კონტროლები

- **ასოს გარეშე ან უცნობი ასოთი სვეტი** — დაწერა იბლოკება, სანამ ყველა სვეტი არ იქნება მონიშნული.
- **დუბლირების დაცვა** — უკვე დაწერილი დოკუმენტის ნომრები მეორედ არ დაიწერება (იგივე დღის ფაილის ხელახლა ატვირთვა იბლოკება).
- **საკონტროლო ჯამი** — წაკითხული რაოდენობების ჯამი დარდება 1C-ის "სულ" სვეტს; შეუსაბამობისას ჩანს გაფრთხილება.
- **ტიპის შეუსაბამობა** — თუ 1C-ის დოკუმენტი ჩამოწერაა, მაგრამ მონიშნულია "მ", ჩანს გაფრთხილება (დაწერა არ იბლოკება).
- **ახალი SKU** — თუ კოდი ნაშთებში არ არის, ავტომატურად ემატება ნაშთით 0 და ნარინჯისფრად ინიშნება.
- **უარყოფითი ნაშთი** — დაწერის შემდეგ ჩანს სია, თუ რომელიმე SKU-ს ნაშთი უარყოფითი გახდა (ნიშნავს არასწორ საწყის ნაშთს ან არასწორ ასოს).

## მნიშვნელოვანი წესები

1. სააღრიცხვო ფაილში **ხელით მხოლოდ "საწყისი ნაშთი" სვეტი ივსება** — ჟურნალს, "მიმდინარე ნაშთს" და "დღიური ნაშთები" ფურცელს აპლიკაცია მართავს. "დღიური ნაშთები" ყოველ დაწერაზე თავიდან იგენერირება ჟურნალიდან, ამიტომ საწყისი ნაშთის შესწორება მასზეც აისახება.
2. ყოველთვის **ბოლო გადმოწერილი ვერსია** გამოიყენეთ შემდეგი დღისთვის. რეკომენდებულია ძველი ვერსიების შენახვა ცალკე საქაღალდეში (ბექაფი).
3. "მიმდინარე ნაშთი" Excel-შიც ცოცხალი ფორმულაა (საწყისი + ჟურნალი), ამიტომ საწყისი ნაშთის შესწორება ავტომატურად აისახება.

## ცნობილი შეზღუდვები

- ოპერაციის კლასიფიკაცია ხელითაა — მცდარი ასო მცდარ ნაშთს იძლევა. ტიპის შეუსაბამობის გაფრთხილებები ამას ნაწილობრივ იჭერს.
- ერთი საწყობი (2 ფეიქრების მიმღები). მეორე საწყობისთვის ცალკე სააღრიცხვო ფაილია საჭირო.
- ბრუნვის (stock-turn) მაჩვენებლები ამ ვერსიაში არ ითვლება — ჟურნალი უკვე შეიცავს ყველა საჭირო მონაცემს და შემდეგ ვერსიაში დაემატება.
